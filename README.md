# Arbeitszeit-Rechner
Dieses Programm soll die Beginn und End Zeit bekommen und die Differenz zur Regelarbeitszeit berechnen.

Dazu kommt das man die tägliche Arbeitszeit speichert in .txt oder .json oder whatever.
Das wird benötigt um die kumulative Arbeitszeit zu berechnen.

Als letztes soll die Datei in .xlsx mit einem bekannten Format gespeichert werden.
